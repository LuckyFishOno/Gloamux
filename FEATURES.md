# Gloamux features

[繁體中文](FEATURES.zh-TW.md) · [Back to README](README.md)

- **Connections** · Organize hosts in a folder tree. Click a folder to open or close it. Drag an item above or below another to reorder it, onto a folder to move it inside, or onto **Root folder** to move it to the top level. Searching for a folder lists everything inside it. The sort button next to **+** lists items in your custom order or by name, ascending or descending, with folders first. While sorted by name, dragging only moves an item into a folder, and the custom order is kept for when you switch back. Hide or show the tree with the sidebar button or ⌃⌘S. Open sessions in tabs or separate windows.
- **Terminal** · Open your local shell with ⌘T. Drag a tab onto the left, right, top, or bottom edge of a pane to split it on that side, or onto the middle of a pane to show it there. A split shows as one **Workspace** tab whose tooltip lists its panes, and each pane has its own header. Drag a pane header to another edge to move it, or onto the tab bar to make it a separate tab again. The × in a pane header disconnects and closes that session. Tabs shrink to fit the bar, down to an icon. You can also use ⌘D to split the current pane side by side or ⇧⌘D to split it top and bottom. Only connected sessions and local terminals split; a tab still showing its sign-in form stays on its own. Every pane can be split again, and the dividers can be dragged. ⇧⌘↩ maximizes or restores a pane, and ⌥⌘I types into all panes at once. The cursor follows the shell while the mouse selects terminal text. Text rewraps when the width changes, so long lines are not cut. Right-click a tab to duplicate it or move it to its own window; the button at the right of that window's title bar puts it back in the tab bar, still connected. A tab you are not looking at shows a ring when new output arrives, and a tab whose connection dropped shows a red mark.
- **Quick commands** · Save and search single-line commands in the right sidebar. Insert one into the selected terminal for editing, or confirm the command and destination before running it.
- **SSH** · Connect with a password, an Ed25519, ECDSA, or RSA key, or keys from `ssh-agent`. Review host fingerprints on first use. Servers that ask their own sign-in questions (keyboard-interactive), such as a verification code after the password or key, show them in a sheet; the session's password answers the first password question, and answers are never saved. Chain up to eight jump hosts or connect through a SOCKS4, SOCKS4a, SOCKS5, or HTTP CONNECT proxy.
- **Port forwarding** · Start local, reverse, and dynamic SOCKS forwards from an SSH tab. Save rules in the connection profile to start them whenever it connects. Listeners use loopback by default. In the Workbench layout, **Tunneling** lists every connected SSH session of the window with its running forwards and their connection counts. Stop a forward there, or choose **Manage** to edit that session's rules.
- **X11** · Start XQuartz, from the Workbench layout's **X server** button or with `gloamux xserver start`, and enable **Forward X11** in a trusted SSH session's properties. Remote X11 programs open on your Mac while that SSH shell is open.
- **File protocols** · Choose FTP, explicit FTPS, or implicit FTPS in the connection editor. For SSH, choose SFTP, legacy SCP, or automatic SCP fallback when the server has no SFTP subsystem. The file browser and transfer queue use the selected protocol. FTPS encrypts commands and data, and each data connection resumes the control connection's TLS session for servers that require it. `gloamux files` uses the same protocols from the command line.
- **Password vault** · Optional. Without it, a password that signs in is remembered on this Mac with a Secure Enclave key and connects again without asking. Those passwords stay on this Mac when you create the vault. The vault is a separate store under your master password. Unlock it once after opening Gloamux, and no connection asks for Touch ID or the Mac password until you lock it or quit. While it is locked, a session with **Confirm each connection with Touch ID** asks each time; other sessions connect with the password remembered on this Mac. If only the locked vault holds a password, that one prompt reads it with Touch ID (set up by the first master-password unlock of this launch); the vault stays locked. When the vault section is collapsed and locked, its Touch ID button unlocks it. An account already in the vault shows **In vault** in the connection form; open it to update the password with the one typed, or to remove it. **Add to vault** saves a password before it has signed in.
- **Secure Enclave key** · Choose **Create public key** next to the key picker. Gloamux creates a P-256 key in this Mac's Secure Enclave, keeps it in its own data folder, and uses it for a connection that has no key yet. The button then becomes **Show public key**, which shows the OpenSSH public key to copy or regenerate. Connections that use it need no fingerprint.
- **Sign in once** · After a password or key passphrase works, Gloamux keeps it on this Mac, so later connections need no typing. A new connection starts with **Confirm each connection with Touch ID** turned on in its properties; sessions saved earlier keep their setting. While the vault is unlocked, it does not ask. **Saved passwords** lists them after Touch ID or the Mac password, with the sessions that use each one, to show, copy, or delete. A copied password is cleared from the clipboard after 60 seconds. Removing a key with × asks first. Then the saved session stops using it, and the account's saved password and the key's passphrase are deleted while the vault is unlocked, so the next connection, also from the session tree, needs the password typed again. An older Secure Enclave key that still asks for Touch ID shows **Needs Touch ID**; switch to the Gloamux key to stop the prompt.
- **Reopen saved connections** · Double-click a saved terminal connection in the tree to open a new tab. If the server's host key changes, verify the new fingerprint before choosing **Update key and reconnect**. Typing `exit` or `logout` closes the tab. If the connection drops, the tab stays open with **Reconnect**.
- **Files sidebar** · In the Default layout, the sidebar on the right shows the focused pane's files as a folder tree: a server pane opens at its login folder, and the local terminal opens at this Mac's home folder. Click a pane and the tree switches to it. Hide or show it with the **Files** button in the toolbar, and drag its edge to resize it. It works like Finder: click the arrow to expand a folder, double-click to go into it, and use `..` or ⌘↑ to go back up. ⌘-click or ⇧-click selects several files to download at once. For a server, **Upload** in the sidebar title picks one or more files to send to the selected folder. You can also drop Finder files on a folder, and right-click to download, rename, delete, or create folders.
- **Transfer progress** · Each upload and download gets its own row at the bottom of the file sidebar with percent, time left, and size left of the total. New rows slide in at the top and up to five show at once; older ones slide out at the bottom. The progress bar shows only while a transfer runs, and a finished row stays for 10 seconds.
- **File Transfer** · A two-pane view like WinSCP or FileZilla: this Mac on the left, a connected server on the right, and the transfer queue below. Drag files between the panes or use the arrows. Folders copy with everything inside them. When names are already taken, choose **Replace** or **Skip existing**. Transfers write to a temporary name first, so a failed or cancelled transfer leaves the existing file intact. When the connection breaks, a transfer tries again after 2, 5, and 10 seconds, and SFTP and FTP copies continue where they stopped. A failed transfer has a **Try again** button in the queue. Right-click a remote item for **Change permissions** or **Edit on this Mac**, or drag it to Finder to copy it there. In the Default layout, switch the toolbar's **Terminal | File Transfer** control: the main window shows the two panes, and the tab bar picks the server, so no extra window opens. The Classic layout's **File Transfer** toolbar button opens it in its own window. The Workbench layout keeps its SFTP panel, and **Two-pane** next to the panel title opens the same window. That window has a server menu at the top.
- **Shell integration** · Local zsh reports each prompt, command, exit status, and folder; for bash, zsh over SSH, or another local shell, choose **Terminal › Enable shell integration**, or turn it on for every SSH session in **Settings › Terminal**. Then ⌘↑ and ⌘↓ jump between prompts, ⇧⌘A selects the last command's output, and the pane header shows its result and how long it ran; click it for the command history. When a command that ran 10 seconds or longer (adjustable) finishes in a tab you are not looking at, the tab gets a dot and macOS shows a notification. ⌘T opens in the folder of the focused local terminal. ⌘-click a link to open it: links that programs mark (OSC 8) and plain web addresses.
- **Command palette** · ⇧⌘P finds a saved session, an open tab, or any workspace action, such as splits, layouts, themes, recordings, and runbooks. Type `user@host` to connect directly.
- **Menu bar** · The terminal icon in the menu bar finds and opens saved sessions, reopens recent ones, starts and stops sessions with saved forwarding rules (showing how many forwards are running), and lists tabs whose commands finished. Hide it in **Settings › Terminal**.
- **Spotlight and Shortcuts** · Saved sessions appear in Spotlight by name, user, and host (never passwords); choosing one opens it. Shortcuts offers **Open Saved Session** and **New Local Terminal**. `gloamux://open?id=<session>` and `gloamux://new-terminal` links do the same.
- **Remote editing** · **Edit on this Mac** opens a remote file of up to 100 MB in its default Mac app, or TextEdit. After you save it there, the file sidebar and the File Transfer queue show **Upload**. Gloamux checks that nobody changed the server's copy since you opened it, asks before replacing it, and keeps the file's permissions.
- **Quick Look** · Right-click a file in the file sidebar or File Transfer and choose **Quick Look**, or press Space in File Transfer. Remote files up to 100 MB are copied to a private temporary folder for the preview and deleted afterward. **Follow terminal folder** at the bottom of the file sidebar keeps the tree on the shell's current folder. It is off by default.
- **Environments** · Tag a session or folder as Production, Staging, Test, or Development from its right-click menu; sessions inherit their folder's tag. The tag colors the tab, frames the pane, and shows in the toolbar and the session window's title. In the environments chosen in **Settings › Safety** (Production and Staging at first), a command that matches a risky pattern, such as `rm -rf`, `DROP TABLE`, `kubectl delete`, or `terraform destroy`, waits for you to confirm it. The patterns are editable.
- **Other connections** · Open or save serial ports, Telnet, Mosh, containers, Kubernetes pods, and AWS Systems Manager sessions from the **Other connection** section of the new connection tab. A serial port takes its device from the list of connected ones, a speed from 300 to 921600, data bits, parity, stop bits, RTS/CTS, DTR/DSR, or XON/XOFF flow control, and a text encoding. Mosh uses the tool installed in your login shell. Telnet and serial ports open directly in Gloamux. The container and pod pickers can list running targets. A new connection opens on the section, and the kind of other connection, used last.
- **Remote desktop** · Choose **Windows Remote Desktop (RDP)** or **Remote Desktop (VNC)** under **New connection**, or expand the RDP or VNC section in the new connection tab, which lists SSH, RDP, VNC, and Other connection from top to bottom. **Remember password** keeps the password after the first successful sign-in. Use the connection manager to save and edit desktop profiles. Sign in and control the desktop in a Gloamux tab. RDP checks the server certificate and supports Network Level Authentication. VNC supports a classic password or a Mac account name and password for macOS Screen Sharing. Only the VNC sign-in is encrypted, so choose a saved SSH session under **Through SSH** to carry the whole connection over SSH; this works for RDP too. An RDP desktop follows the size of its pane by default; in the connection settings choose a fixed **Resolution** (scaled to fit the pane), **Optimize for Retina displays** for sharper text, and a **Connection quality** from Best quality (LAN) to Fastest (slow network). The header has a full screen button, and a dropped connection reconnects on its own when **Reconnect automatically** is on in Settings. With **Share clipboard** on in the connection settings, text copied on either side can be pasted on the other, for both RDP and VNC. Printers, smart cards, sound, microphones, cameras, and shared folders are not redirected.
- **Multiple windows** · Use **File › New Window**, press **⌘N**, or right-click the Dock icon and choose **New Window**. Each window has its own tabs and uses the same saved connections. Closing the last workspace window quits Gloamux.
- **Host discovery** · **Discover hosts** finds SSH services on this network through Bonjour, Tailscale peers, and EC2 instances through the AWS command-line tool with your profile. Review them, choose a username, and add the ones you want to a new folder. EC2 instances can be added as SSM sessions.
- **Reachability and host keys** · A dot after each visible saved host shows whether its SSH port answers (checked every 90 seconds without signing in; turn it off in **Settings › Safety**). **Host key history** in Settings lists every host key you trusted, replaced, or declined, and changed keys that blocked a connection.
- **Runbooks** · Write Markdown runbooks with `sh`, `bash`, `zsh`, or `console` blocks. Choose a session, then run one block or all of them after confirming the commands and destination; a warning appears for tagged environments. With shell integration, Gloamux waits for each block, stops at the first failure, and keeps each block's exit status and output.
- **Recordings** · ⌥⌘R records what a terminal shows, never what you type. Access keys, tokens, private keys, and password values are replaced with `[REDACTED]` when the recording is saved. Replay recordings in **Recordings** at up to 4× speed, or export them as asciinema `.cast` files.
- **Find and logs** · ⌘F searches the terminal and its scrollback as plain text or a regular expression and highlights every match; ⌘G and ⇧⌘G step through them. ⌥⌘L saves what a terminal shows to a session log, as plain text or with escape sequences, with likely secrets masked. **Settings › Terminal** can log every session.
- **Text and cursor** · **Settings › Text** sets the font, its size, a block, underline, or bar cursor that can blink, and the background's opacity over a blurred desktop. ⌘+, ⌘−, and ⌘0 change the size from any terminal. **Application font size** (8–28 pt) sizes the rest of the interface, including buttons, pop-up menus, and right-click menus; when your last click was outside a terminal, or with ⌥ added, the same keys change it.
- **Terminal programs** · vim, tmux, htop, and similar programs get mouse clicks, drags, and the wheel; hold Option to select text instead. Input methods compose over the cursor. **Terminal › Text encoding** switches a session to Big5, GB18030, Shift JIS, EUC-JP, EUC-KR, or ISO Latin 1, and saved sessions remember it. Pasting several lines shows them first so you can check or edit them. The bell flashes the terminal or plays a sound, and marks a tab you are not looking at. Programs can copy to your clipboard with OSC 52 only after you allow it in **Settings › Terminal**, and they can never read it.
- **Import** · Preview sessions before importing them from an Xshell session file or folder, an OpenSSH configuration, a MobaXterm export (`.mxtsessions` or `MobaXterm.ini`), PuTTY or KiTTY sessions exported from the registry (`.reg`), a CSV file, or a Gloamux sessions file. Gloamux keeps folders and reads users, ports, keys, proxies, and jump hosts. MobaXterm SSH gateways and PuTTY SSH proxies become jump host sessions, and PuTTY port forwards are kept. Passwords are never imported. The preview lists skipped entries and settings to review, such as key files that were on Windows.
- **Export** · Export all sessions, or one folder from its right-click menu, as a Gloamux sessions file or a CSV file. Neither includes passwords, so the file can be shared with a team. Key paths in the home folder are written as `~/…` and point to each teammate's own home folder on import. A CSV file needs a `host` column. Optional columns are `folder` (for example `Team/Prod`), `name`, `port`, `username`, `protocol` (`ssh` or `sftp`), `identity file`, `proxy type`, `proxy host`, `proxy port`, and `jump` (another row's `folder/name`, or `user@host:port`).
- **Appearance** · Choose from 73 workspace themes in the right sidebar. They include Ubuntu, Kali, GNOME, KDE Breeze, Tango, and Linux console palettes and popular Visual Studio Code themes such as GitHub, One Dark Pro, Dracula, Tokyo Night, Catppuccin, Nord, and Gruvbox. Search the list by name. Every terminal uses the selected workspace theme. The **Settings** window (⌘,) also offers the themes. Changes in Settings apply at once; close the window with its standard close button.
- **AI agents (MCP)** · Off until you turn it on in **Settings › Agents**. An agent such as Claude Code or Codex connects by running `gloamux mcp`, shown there with a copy button. It sees only the sessions you allow, from that pane or a session's right-click menu, by name and destination, and never receives passwords or keys. It can open an allowed session in Gloamux, read text you share with **Terminal › Share with Agents** (the selection, the last command's output, or the screen), and propose a command. Gloamux brings the tab forward and shows the agent, session, destination, reason, and the full command; it runs only when you choose **Run**, and only in the same live terminal. The pane keeps a history of every request, including refused ones, and **Revoke all access** stops everything at once, including commands waiting for review.
- **All settings in one file** · **Export** in **Settings › General** saves sessions with their accounts, quick commands, triggers, runbooks, host keys, the theme, the layout, settings, and the password vault in one `.gloamuxconfig` file, with a `.sha256` file next to it. The vault stays sealed under its master password, which is not saved in the file; passwords remembered on this Mac are not included. **Import** checks the file against its `.sha256`, replaces all of these, and restarts Gloamux; the previous ones are kept in the `Backups` folder of Gloamux's data folder first. A backup without a vault leaves the current vault alone, and passwords remembered on this Mac stay as they are. From the command line, use `gloamux config export PATH` and, with Gloamux closed, `gloamux config import PATH`.
- **Language** · The interface is available in English, Traditional Chinese, Simplified Chinese, Japanese, and Spanish. By default it follows the Mac's language. Choose another in **Settings › General** or in System Settings › General › Language & Region › Applications. Gloamux's own text changes at once, and the menus macOS draws change the next time Gloamux opens.
- **Workspace layout** · Pick a layout from the layout menu at the right end of the toolbar. It applies at once and is remembered. Every layout uses the same connections, themes, and tools.
  - **Default** keeps a Mac toolbar, flat tabs, floating panes, and the file tree on the right.
  - **Classic** adds an icon toolbar, an address bar that takes `ssh://user@host:port`, `user@host`, or a host, the session manager on the left, and boxed tabs. A compose bar under the terminal sends a line to the current session or to every open session. The toolbar also starts and stops the session log, imports a highlight set, opens the triggers in Settings, and locks the workspace. The status bar shows the address, protocol, terminal size, cursor position, session count, and Caps Lock.
  - **Workbench** adds a ribbon of large buttons and a vertical side rail that switches the left panel between Sessions (with quick connect), SFTP, and Macros (quick commands). Tabs are numbered. **MultiExec** types what you type into every terminal of the window at once, split or not, except read-only ones. **X server** starts XQuartz, **Saved passwords** opens the saved passwords after Touch ID or the Mac password, and **Tunneling** opens the tunnel list. **Follow terminal folder** under the SFTP browser shows the folder the remote shell is in after each command. If the shell does not report its folder, Gloamux types a one-line prompt hook into it. A monitoring bar under the terminal shows CPU, memory, network, uptime, users, and disk use for this Mac or for a Linux server.

## Command-line tool

`Gloamux.app` includes the `gloamux` command, and `gloam` as a short name for it.

Use `gloamux sessions list` to find a saved profile, then `gloamux files ls --session "Work server" --json` to browse its files. The file commands support uploads and downloads of files or, with `--recursive`, whole folders, resume where supported, and file management, including removing a folder with its contents, over SFTP, SCP, FTP, and explicit or implicit FTPS. Transfers read saved settings and trust without changing them, so they can run while the app is open.

`gloamux ssh "Work server"` opens a saved SSH session's shell in the terminal you run it from, signed in the same way, and exits with the remote shell's exit status.

The CLI also manages sessions (including serial, Telnet, Mosh, container, pod, and SSM sessions with `gloamux sessions add-other`), the rest of the connection form (jump host, proxy, startup commands, agent and X11 forwarding, file protocol, encoding, and whether a session asks on every connection with `gloamux sessions options`; the RDP and VNC SSH tunnel, resolution, Retina, quality, and clipboard with `edit-other`), folders, environment tags, host keys and their history (remove, export as `known_hosts`, clear the history), host discovery over Bonjour, Tailscale, and AWS (`gloamux hosts discover`), recordings (`gloamux tabs record` and `gloamux recordings list|export|remove`), forwarding rules, quick commands, output triggers, runbooks, themes, settings, and the layout. With Gloamux open, `gloamux tabs list` lists the tabs of every window with an ID that stays the same while the tab is open. Use those IDs to select, rename, duplicate, split, disconnect, reconnect, or close tabs, apply an Xshell color scheme or highlight set, read what a terminal shows, type text or a saved quick command into it, or run a runbook there, record it, enable shell integration, or switch the window between the terminal and file transfer with `gloamux tabs view`. `gloamux tabs multiexec TAB_ID on` types into every terminal of that tab's window, and `gloamux forwards live-list` lists every connected SSH tab with its running forwards and connection counts. `gloamux tabs connect user@host` opens a connection without saving it. A risky command in a confirming environment waits for your answer in Gloamux, as if you had typed it there. `gloamux vault lock` and `gloamux workspace lock` lock Gloamux, and `gloamux signins list` lists saved passwords after Touch ID or the Mac password, without printing them. `gloamux xserver status` and `gloamux xserver start` check and start XQuartz without Gloamux open. Ctrl-C stops a file transfer and removes its partial file. See the [command-line setup and examples](README.md#command-line) for authentication options, exit codes, and Zsh and Bash completion.

Set the layout:

```sh
./build/Gloamux.app/Contents/Resources/bin/gloamux layout get
./build/Gloamux.app/Contents/Resources/bin/gloamux layout set workbench
```

The available values are `default`, `classic`, and `workbench`. With Gloamux open, the active window switches at once; otherwise the next launch uses it.

Measure terminal performance:

```sh
./build/Gloamux.app/Contents/Resources/bin/gloamux benchmark
```

It reports parser throughput for several kinds of output, full-redraw time, and keystroke echo time. The [development guide](DEVELOPMENT.md) has the current numbers.

Stress-test the app, the CLI, and agent access, and record CPU and memory use:

```sh
python3 Gloamux/scripts/stress-test.py --quick
```

It uses a throwaway workspace and a throwaway SSH server on this Mac, and writes a report. Leave out `--quick` for the full load. The [development guide](DEVELOPMENT.md) describes the phases.
