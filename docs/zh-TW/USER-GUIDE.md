## 1. 視窗

### 版面

從工具列最右邊的 **版面** 選單切換版面，立即套用並會記住。三種版面使用相同的連線、主題和工具。

| 版面 | 樣子 |
|---|---|
| **預設** | Mac 工具列、平面分頁、浮動窗格，左邊是連線樹，右邊是檔案側欄。 |
| **經典** | 圖示工具列、網址列、左邊的連線管理員、方框分頁、輸入列和狀態列。 |
| **工作台** | 大按鈕功能區、有編號的分頁，以及切換左側面板（工作階段、SFTP、巨集）的側邊列。 |

### 預設版面的工具列

| 項目 | 作用 |
|---|---|
| 側欄按鈕（⌃⌘S） | 顯示或隱藏連線樹。 |
| 環境標籤 | 顯示目前工作階段的環境，例如 Production。 |
| **檔案傳輸** / **終端** / **連線歷史** | 在雙欄檔案傳輸、終端和[連線歷史](#連線歷史)之間切換。選一個分頁就會離開連線歷史。 |
| **新連線** 選單 | **新連線**、**本機終端**、**其他連線**、**探索主機** 和 **匯入連線**。 |
| **檔案** | 在右邊顯示或隱藏目前窗格的檔案。 |
| **常用指令** | 打開常用指令側欄。 |
| **工作區主題** | 在側欄打開主題清單。 |
| **版面** | 切換預設、經典和工作台。 |

### 經典版面

- 網址列接受 `ssh://user@host:port`、`user@host` 或主機名稱，按 Return 連線。
- 終端下方的輸入列會把一行文字送到 **目前工作階段** 或 **所有工作階段**。用 **隱藏輸入列** 收起來。
- 工具列也能開始和停止連線紀錄、打開 **連線歷史**、匯入醒目提示、打開設定裡的輸出觸發、分割窗格，以及鎖定工作區。
- 狀態列顯示位址、通訊協定、終端大小、游標位置（`Ln`、`Col`）、選取行數、工作階段數量、收發的資料量和 Caps Lock。

### 工作台版面

- 側邊列把左側面板切換成 **工作階段**（含快速連線）、**SFTP** 或 **巨集**（常用指令）。
- **多重執行** 會把你輸入的內容同時送到視窗裡的每個終端，不論是否分割，唯讀的除外。
- **X 伺服器** 啟動 XQuartz。**已存密碼** 在通過 Touch ID 或 Mac 密碼後打開已存的密碼。**通道** 列出視窗中每個已連線的 SSH 工作階段和正在執行的轉發。
- SFTP 瀏覽器下方的 **跟隨終端資料夾** 會在每個指令執行後，顯示遠端 shell 所在的資料夾。shell 沒有回報資料夾時，Gloamux 會在 shell 中輸入一行提示字元掛鉤。
- 上方按鈕列的 **連線歷史** 會在獨立視窗打開每次連線的紀錄。
- SFTP 面板標題旁的 **雙欄傳輸** 會打開雙欄的檔案傳輸視窗。
- 終端下方的監控列顯示這台 Mac 或 Linux 伺服器的 CPU、記憶體、網路、開機時間、使用者和磁碟用量。

## 2. 連線與連線樹

### 開新連線

1. 選 **檔案 › 新連線**（⇧⌘N），或工具列的 **新連線**。
2. 新連線分頁由上到下列出 **本機**、**SSH**、**RDP**、**VNC** 和 **其他連線**。**本機** 會在目前分頁開啟這台 Mac 的登入 shell。表單會記住上次使用的區塊和其他連線類型；使用本機後，下次表單的其他區塊會保持收合。
3. 填入主機、連接埠和帳號，按 **連線**。
4. 連線成功後，按 **儲存** 把它存進連線樹，Gloamux 會請你取名。

要開這台 Mac 的終端，選 **檔案 › 新本機終端**（⌘T）。**+** 按鈕開啟 **設定 › 終端** 的 **新分頁開啟** 所選的項目：**預設（127.0.0.1）**，也就是這台 Mac 的終端；**新連線表單**；或某個已存連線，會立刻連線。選的已存連線被刪除後，改開預設。**新連線**（⇧⌘N）一律開表單。

### SSH 連線表單

| 欄位 | 用途 |
|---|---|
| **名稱**、**主機**、**連接埠**、**帳號** | 連線目的地。 |
| **通訊協定** | SSH；或只傳檔案的 FTP、**FTPS（明確式，AUTH TLS）**、**FTPS（隱含式 TLS）**。 |
| 金鑰選擇器 | **選擇私鑰** 開啟私鑰檔，選單也提供 **產生新金鑰檔**。**建立公鑰**／**查看公鑰** 管理 Gloamux 的 Secure Enclave 金鑰。見[金鑰](#金鑰)。 |
| **每次連線用 Touch ID 確認** | 使用金鑰或記住的密碼連線前，先要求 Touch ID。第一次連線還沒有保存任何東西，不會詢問。 |
| **SSH 跳板** | 依序經由其他已存連線連過去，最多八層。**新增跳板** 加入下一層，× 移除該層。只有第一層會再使用它自己的跳板設定。連上後，窗格標題列會顯示路徑（A › B › D）；點一下可以看每台主機的位址和主機金鑰，按 **從每台伺服器確認** 會列出每台伺服器收到的連線來自哪裡，每一台都應該是它上面那一台。終端、遠端檔案和連接埠轉發都走同一條路徑。 |
| **代理類型**、**代理伺服器**、**代理連接埠** | SOCKS4、SOCKS4a、SOCKS5 或 HTTP CONNECT。 |
| **轉送 SSH agent** | 讓伺服器在這個工作階段使用這台 Mac 的 SSH agent。 |
| **轉發 X11** | 在這台 Mac 顯示遠端的 X11 程式（需要 XQuartz）。 |
| **連線後顯示遠端檔案** | 連線時打開檔案側欄。 |
| **啟動命令** | shell 開啟後自動輸入的指令。 |
| **檔案傳輸** | **SFTP，沒有 SFTP 時用 SCP**、**只用 SFTP** 或 **只用 SCP**。 |
| **信任的憑證** | FTPS 伺服器憑證中你核對過的 SHA-256 指紋。 |

### 連線樹

- 按資料夾即可展開或收合。按兩下已存的終端連線，會在新分頁開啟。
- 用方向鍵可在連線樹中移動、展開或收合資料夾。Return 會開啟選取的連線，或展開、收合選取的資料夾；Delete 會先確認再刪除選取的項目。直接打字可跳到同名項目。
- 把項目拖到兩列之間就會放在那裡，拖到資料夾中間會移進去，拖到最後一列下方會移到最上層。拖到資料夾列的上緣或下緣，會排在該資料夾前面或後面，所以資料夾也能像連線一樣互換位置。拖到連線樹上緣或下緣時會自動捲動，拿著項目停在收合的資料夾上，資料夾會自動展開。
- **+** 旁的排序按鈕可選自訂順序、**名稱升序** 或 **名稱降序**，資料夾一律排在前面。依名稱排序時把項目拖到兩列之間，會把畫面上的順序存成自訂順序並切換到 **自訂**，項目就留在放下的位置。
- **搜尋連線** 會篩選連線樹；搜尋資料夾名稱會列出其中所有項目。
- 每個可見的已存主機後面有一個圓點，顯示主機能否連線。見[安全](#11-安全)。

**+** 選單提供 **新增資料夾**、**儲存目前連線**、**其他連線**、**探索主機**、**匯入**、**匯出所有連線**、**全部展開**、**全部收合** 和 **貼到根資料夾**。

在連線上按右鍵：

| 項目 | 作用 |
|---|---|
| **在分頁開啟** / **在新視窗開啟** | 開啟連線。 |
| **連線設定** | 編輯連線表單。 |
| **重新命名**、**複製**、**剪下**、**貼上**、**刪除** | 管理項目。刪除只會移除已存的項目，不影響已開啟的連線和遠端檔案。 |
| **環境** | 標記為 Production、Staging、Test 或 Development。 |
| **允許 AI 代理** | 讓 AI 代理使用這個連線。見[AI 代理](#15-ai-代理mcp)。 |

在資料夾上按右鍵，有 **在分頁開啟資料夾內的所有連線**、**將目前連線存到這裡**、**新增資料夾**、**匯出資料夾**、**環境**（資料夾內的連線會沿用），以及相同的編輯項目。

### 探索主機

**探索主機** 會透過 Bonjour 找出這個網路上的 SSH 服務、Tailscale 的其他裝置，以及用你自己的 AWS 設定檔找出執行中的 EC2 執行個體。檢查清單、選擇帳號，再把要的主機加到新資料夾。EC2 執行個體可以加成 AWS Systems Manager（SSM）連線。你選擇之前不會加入任何東西。切換來源或關閉視窗會停止進行中的搜尋。Tailscale 和 AWS 工具必須在時限內完成，輸出最多 16 MB。

## 3. SSH

### 登入方式

- 密碼、Ed25519、ECDSA 或 RSA 金鑰、`ssh-agent` 的金鑰，或這台 Mac Secure Enclave 裡的 Gloamux 金鑰。
- 伺服器自己提出的問題（keyboard-interactive），例如輸入密碼後的驗證碼，會顯示在對話框中。連線的密碼會回答第一個密碼問題。答案絕不會被儲存。
- 已存連線設定裡的 **登入方式** 可選 **密碼或金鑰**、**每次回答伺服器的問題**（不存密碼，所有問題都會顯示）或 **每次輸入 session key**。

### SFTP 閘道與 session key

有些存取閘道只允許 `sftp`，並且每次給一組新的 session key 代替使用者名稱。

- 在連線樹的 **+** 選單或指令面板選 **從 sftp 指令新增工作階段**，或直接把指令貼進面板。指令可以跨行，也可以包含 `lcd`、`cd`、`get` 和 `put`。
- Gloamux 會讀出主機、連接埠、登入方式和資料夾，用不到的選項列在 **未包含**。會改變連線路徑或執行程式的選項（例如 `-J`、`ProxyCommand`）會被拒絕。
- **儲存並連線** 會存成連線，並傳輸指令裡的檔案。**取代既有檔案** 預設關閉。
- 之後開啟這個連線，只要輸入新的 key。可以貼 key 本身、`key@host`，或整段新指令；如果指令的主機或連接埠不同，會被拒絕。
- key 只留在記憶體，直到 Gloamux 結束、密碼庫鎖定或伺服器拒絕為止，絕不會被儲存。這類連線不會自動重連，也不能當跳板。
- 連線設定裡的 **遠端資料夾** 和 **這台 Mac 的資料夾** 決定檔案傳輸一開始打開哪裡。

### 主機金鑰

- 第一次連到伺服器時會顯示它的指紋。信任之前，請和伺服器真正的指紋比對。
- 伺服器的金鑰改變時，連線會停下。核對新指紋後，再選 **更新金鑰並重新連線**。
- **設定 › 安全 › 主機金鑰紀錄** 列出你信任、取代或拒絕過的每把金鑰，以及擋下連線的已變更金鑰。

### 重新連線

- 輸入 `exit` 或 `logout` 會關閉分頁。
- 連線中斷時，分頁會保留並顯示 **重新連線**，分頁上也會出現紅色標記。
- 在 **設定 › 終端** 打開 **自動重新連線** 後，已存連線會在 2、5、10、30 和 60 秒後重新連線。按 **中斷連線** 或關閉分頁就會停止，正在嘗試時也一樣。Mac 從睡眠喚醒後，所有連線會立刻檢查一次。

### 連接埠轉發

1. 在已連線的 SSH 窗格，按窗格標題列的 **連接埠轉發** 按鈕（⇄）。
2. 選擇 **轉發類型**：**本機連接埠轉發**、**反向連接埠轉發** 或 **動態 SOCKS 代理**，再輸入連接埠；本機和反向轉發還要填 **目的地主機** 和 **目的地連接埠**。
3. 按 **啟動轉發** 立即執行，或按 **儲存規則** 讓它在每次連線時自動啟動。

**已啟動的轉發** 列出正在執行的轉發和連線數，按 **停止** 可結束。監聽預設只綁定本機回送位址。工作台版面的 **通道** 列出所有轉發和連線數，可以在那裡停止，或按 **管理** 編輯該連線的規則。選單列圖示也能啟動和停止有已存規則的連線。

### X11 轉發

1. 用工作台的 **X 伺服器** 按鈕或 `gloamux xserver start` 啟動 XQuartz。
2. 在信任的連線設定中打開 **轉發 X11**。
3. 只要那個 SSH shell 開著，遠端 X11 程式就會在這台 Mac 上開啟。

## 4. 密碼、金鑰與密碼庫

### 只需登入一次

密碼或金鑰密語成功登入後，Gloamux 會用 Secure Enclave 金鑰加密並保存在這台 Mac，之後連線不必再輸入。新連線預設打開 **每次連線用 Touch ID 確認**，可以在連線設定中關閉。新連線第一次連線時還沒有保存任何東西，所以不會詢問；輸入密碼後，之後的連線會在使用它前詢問。

**已存密碼** 在通過 Touch ID 或 Mac 密碼後列出這些密碼，以及使用它們的連線，可以顯示、拷貝或刪除。拷貝的密碼會在 60 秒後從剪貼簿清除。

### 密碼庫（選用）

密碼庫是另一個以主密碼加密的儲存區。

- 打開 Gloamux 後解鎖一次，在鎖定或結束前，連線都不會再要求 Touch ID 或 Mac 密碼。
- 密碼庫鎖定時，打開 **每次連線用 Touch ID 確認** 的連線每次都會詢問；其他連線使用這台 Mac 記住的密碼。
- 密碼庫區塊收合且鎖定時，它的 Touch ID 按鈕可以直接解鎖。
- 已在密碼庫中的帳號，會在連線表單顯示 **已存入密碼庫**。點開後可以用剛輸入的密碼更新，或將它移除。**存入密碼庫** 可以在密碼登入成功前先存起來。
- **鎖定密碼庫** 會立即鎖定。建立密碼庫之前記住的密碼，仍會保留在這台 Mac。

### 金鑰

- **選擇私鑰** 使用現有的私鑰，例如 EC2 的 `.pem` 檔。選單提供 **選擇金鑰檔** 和 **產生新金鑰檔**。產生功能會在 `~/.ssh` 寫入 Ed25519 私鑰和 `.pub` 公鑰檔，可設定密語和註解。私鑰保留在 Mac，公鑰放進伺服器的 `~/.ssh/authorized_keys`。
- **建立公鑰** 會在這台 Mac 的 Secure Enclave 建立 P-256 金鑰。**查看公鑰** 顯示這把 Gloamux 金鑰的 OpenSSH 公鑰，與旁邊所選的私鑰檔各自獨立。按 **這條連線使用此金鑰** 即可使用 Secure Enclave 金鑰。**重新產生** 會取代它，伺服器也需要更新公鑰。
- 用 × 移除金鑰前會先詢問。已存連線會停止使用它；密碼庫解鎖時，該帳號的已存密碼和金鑰密語也會一併刪除。
- 仍會要求 Touch ID 的舊版 Secure Enclave 金鑰會顯示 **需要 Touch ID**，改用 Gloamux 金鑰即可停止詢問。

### 鎖定工作區

**視窗 › 鎖定工作區**（⌃⌘L）會遮住所有終端，直到你用 Touch ID 或 Mac 密碼解鎖。**設定 › 一般 › 鎖定工作區** 可以在一段時間沒有使用後自動鎖定。

每個視窗各自鎖定。視窗鎖定期間，`gloamux` 指令和代理都無法讀取、輸入或變更它的分頁，即使透過另一個視窗送出也一樣。`gloamux tabs list` 只會列出這些分頁的名稱，runbook 或已確認的指令也要等你解鎖後才會在那裡繼續。

## 5. 終端

### 基本操作

- 用滑鼠選取文字時，游標仍跟著 shell。寬度改變時，文字會重新換行。
- 輸入法的組字會直接顯示在游標上。
- ⌘-按一下可開啟連結，包括程式標記的連結（OSC 8）和一般網址。
- vim、tmux、htop 這類程式可以收到滑鼠點按、拖曳和滾輪；按住 Option 則改為選取文字。
- 貼上多行文字時會先顯示內容，讓你檢查或修改。
- 響鈴會讓終端閃一下或發出聲音，並標記你沒在看的分頁。
- **終端 › 文字編碼** 可以把連線切換成 UTF-8、Big5、GB18030、Shift JIS、EUC-JP、EUC-KR 或 ISO Latin 1，已存連線會記住。
- **終端 › 唯讀** 讓你的輸入不會送到這個連線。

### Shell 整合

本機 zsh 會回報每個提示字元、指令、結束狀態和資料夾。bash、透過 SSH 的 zsh 或其他本機 shell，請選 **終端 › 啟用 Shell 整合**，或在 **設定 › 終端** 打開 **SSH Shell 整合**。之後：

- ⌘↑ 和 ⌘↓ 在提示字元之間跳轉，⇧⌘A 選取上一個指令的輸出。
- 窗格標題列會顯示上一個指令的結果和執行時間；點一下打開 **指令紀錄**，可以拷貝指令或它的輸出。
- 在你沒在看的分頁中，執行 10 秒以上的指令（見 **長指令完成時通知**）結束時，分頁會出現圓點，macOS 也會顯示通知。
- ⌘T 會在目前本機終端所在的資料夾開新的本機終端。

### 搜尋

⌘F 以純文字或正規表示式搜尋終端和回捲內容，並標出所有符合的地方；⌘G 和 ⇧⌘G 逐一切換。

### 連線歷史

- 從預設工具列、經典工具列或工作台按鈕列的 **連線歷史** 打開，也可以用 **終端** 選單或指令面板。在已存連線上按右鍵打開時，只顯示符合該名稱的紀錄。
- 列出每一次連線：時間、位置、經過哪些跳板或 Proxy，以及怎麼結束。選一筆可依序看到裡面發生的事：
  - **指令**：在終端執行的每個指令，不論是輸入、從歷史叫回、貼上、廣播，或由快速指令、Runbook、Agent、`gloamux tabs` 送出。
  - **檔案**：下載、上傳、建立資料夾、重新命名、刪除和變更權限。
  - **連線**：經過的跳板和 Proxy、登入、連接埠轉送、在終端執行的每個 `ssh` 是否連上，以及怎麼結束。
- 搜尋可找指令、路徑、主機和名稱。**下載紀錄** 把那一筆存成文字檔；有終端紀錄時會一併附上。
- 指令取自按下 Return 時終端顯示的那一行，所以伺服器不顯示的密碼不會記下，指令裡疑似機密的部分會遮蔽。在編輯器等全螢幕程式裡輸入的文字不會記錄。在 tmux、screen 或 Mosh 裡，提示字元有 `user@host` 時才會記錄指令。在這台 Mac 上開的本機終端不是連線，沒有紀錄。
- 在終端執行 `ssh` 再連到另一台伺服器時，會記下 **SSH 連線成功** 或 **SSH 連線失敗**，失敗時附上 `ssh` 顯示的原因。回答它的問題（例如新主機金鑰的 `yes`）不算指令。`ssh` 不顯示錯誤（`-q`、`-E` 或重新導向）、只開通道不登入（`-N`），或由別名、腳本執行時，不會記下結果。
- 選單可以把清單匯出成 CSV 或 JSON、清除，或關閉歷史或 **記錄指令**。在一筆上按右鍵可刪除。
- 不包含密碼、session key 和指令的輸出，只有 `ssh` 失敗的原因例外。session key 只顯示前四個字元。紀錄保留一年，最多 2,000 筆。

### 連線紀錄

- **終端 › 開始連線紀錄**（⌥⌘L）會把終端顯示的內容存成檔案，格式為純文字或含控制序列，可能的機密會被遮蔽。
- **設定 › 終端 › 記錄每個連線** 會從每個終端開啟時開始記錄。
- **終端 › 顯示連線紀錄** 在 Finder 中打開紀錄資料夾。
- **終端 › 儲存輸出**（⇧⌘S）儲存終端顯示的內容；**在文字編輯器打開輸出** 用文字編輯器打開。

### 錄影

- **終端 › 開始錄影**（⌥⌘R）只錄下終端顯示的內容，絕不錄下你輸入的內容。
- 錄影儲存時，存取金鑰、權杖、私鑰和密碼值會換成 `[REDACTED]`。
- **終端 › 錄影** 可以最快 4 倍速重播，並匯出成 asciinema `.cast` 檔。
- 停止錄影會立即完成；Gloamux 在背景遮蔽機密並寫入檔案，視窗可以繼續操作。同一個分頁在同一秒內停止的兩段錄影會存成不同檔案。
- 錄影無法儲存時，視窗底部會出現 **錄影未儲存**。Gloamux 會保留這段錄影，直到你選 **重試** 或 **捨棄**。
- 結束 Gloamux 時會停止進行中的錄影，並等它們寫入完成。如果有錄影無法儲存，Gloamux 會先詢問：**不要結束** 會保留它以便重試，**仍要結束** 則捨棄它。

### 顏色

**終端 › 匯入配色** 把 Xshell `.xcs` 配色套用到這個連線，**匯入醒目提示** 套用 Xshell 醒目提示組。**改回預設顏色** 回到工作區主題。

## 6. 分頁、窗格與視窗

### 分頁

- 分頁會縮小以塞進分頁列，最小只剩圖示。你沒在看的分頁有新輸出時會出現圓環。
- 在分頁上按右鍵，有 **重新命名分頁**、**複製分頁**、**移到新視窗**、**唯讀**、**分頁左移**、**分頁右移** 和 **關閉**。
- ⌘1 到 ⌘8 依位置選擇分頁，⌘9 選最後一個。⇧⌘] 和 ⇧⌘[ 切換到下一個和上一個分頁。
- 移到獨立視窗的分頁會保持連線。按該視窗標題列右邊的按鈕，或 **視窗 › 移回分頁列**，就能放回來。

### 分割窗格

- 把分頁拖到窗格的左、右、上或下邊緣，就會在那一側分割；拖到窗格中間則改顯示在那裡。
- ⌘D 左右分割目前窗格，⇧⌘D 上下分割。只有已連線的工作階段和本機終端可以分割。
- 分割後會顯示成一個 **工作區** 分頁，滑鼠停在上面會列出所有窗格。每個窗格有自己的標題列；把標題列拖到其他邊緣可移動窗格，拖到分頁列則變回獨立分頁。窗格標題列的 × 會中斷並關閉該工作階段。
- 每個窗格都能再分割，分隔線可以拖曳。
- ⇧⌘↩ 放大或還原窗格。⌥⌘I 同步輸入到分割中的所有窗格。**取消分割** 把窗格變回分頁。

### 視窗

選 **檔案 › 新增視窗**（⌘N），或在 Dock 圖示上按右鍵選 **新增視窗**。每個視窗有自己的分頁，共用相同的已存連線。關閉最後一個工作區視窗會結束 Gloamux。

## 7. 檔案

### 檔案側欄

1. 在預設版面按工具列的 **檔案**。
2. 側欄顯示目前窗格的檔案：伺服器窗格從登入資料夾開始，本機終端從你的個人資料夾開始。點另一個窗格，樹狀清單就會切換過去。
3. 按箭頭展開資料夾，按兩下進入資料夾，用 `..` 或 ⌘↑ 回上一層。

- ⌘-按一下或 ⇧-按一下可以選取多個檔案一起下載。
- 側欄標題的 **上傳** 會把檔案傳到選取的資料夾，也可以把 Finder 的檔案拖到資料夾上。
- 按右鍵有 **開啟**、**展開** 或 **收合**、**快速查看**、**下載**、**重新命名**、**刪除**、**新增資料夾**、**在 Finder 中顯示** 和 **複製路徑**。
- 底部的 **跟隨終端資料夾** 會讓樹狀清單停在 shell 目前所在的資料夾，預設關閉。
- 拖曳側欄邊緣可以調整寬度。

### 傳輸進度

每個上傳和下載都會在檔案側欄底部有一列，顯示百分比、剩餘時間和剩餘大小。最多同時顯示五列，完成的那列會停留 10 秒。

### 檔案傳輸（雙欄）

左邊是這台 Mac，右邊是已連線的伺服器，下方是傳輸佇列。

- 從預設工具列的 **檔案傳輸**（由分頁列選擇伺服器）、經典版面的 **檔案傳輸** 按鈕，或工作台 SFTP 面板的 **雙欄傳輸** 打開。
- 在兩欄之間拖曳檔案，或用箭頭按鈕。資料夾會連同內容一起複製。
- 名稱已存在時，選 **取代** 或 **略過同名檔案**。
- 傳輸會先寫到暫存名稱，再一次換掉原本的檔案，所以失敗或取消的傳輸不會破壞原本的檔案。無法一次換掉檔案的 SFTP 伺服器會拒絕覆寫，並保留原本的檔案。連線中斷時，會在 2、5、10 秒後重試，SFTP 和 FTP 會從中斷處繼續。失敗的傳輸在佇列中有 **重試** 按鈕。
- 在遠端項目上按右鍵，有 **下載**、**在這台 Mac 編輯**、**更改權限**、**重新命名**、**複製路徑**、**快速查看**、**新增遠端資料夾** 和 **刪除**。在本機項目上按右鍵，有 **上傳**、**快速查看**、**在 Finder 中顯示**、**重新命名**、**新增資料夾** 和 **移到垃圾桶**。
- 按空白鍵快速查看。把遠端項目拖到 Finder 即可複製過去。

### 在這台 Mac 編輯

**在這台 Mac 編輯** 會用預設的 Mac App（或文字編輯）打開 100 MB 以內的遠端檔案。在那裡儲存後，檔案側欄和檔案傳輸佇列會顯示 **上傳**。Gloamux 會確認伺服器上的檔案在你打開後沒有被別人改過，取代前會先詢問，並保留檔案權限。

### 快速查看

**快速查看** 可以預覽 100 MB 以內的遠端檔案。檔案會複製到私人暫存資料夾來預覽，之後刪除。

### 通訊協定

SSH 連線使用 SFTP、舊版 SCP，或在伺服器沒有 SFTP 子系統時改用 SCP。FTP 和 FTPS 連線使用 FTP、明確式 FTPS 或隱含式 FTPS。FTPS 會加密指令和資料；一般 FTP 不加密任何內容，包括密碼。

## 8. 遠端桌面

1. 選 **新連線**，展開 **RDP**（Windows 遠端桌面）或 **VNC**（包含 macOS 螢幕共享）。
2. 輸入主機和帳號。**記住密碼** 會在第一次登入成功後保存密碼。
3. 要讓整個連線走 SSH，在 **透過 SSH** 選一個已存的 SSH 連線。VNC 桌面流量沒有加密，SSH 通道可保護這些流量。Mac 帳號登入會加密憑證；傳統 VNC 密碼驗證不會加密桌面串流。桌面只會透過這個連線開自己需要的通道，不會啟動該連線已存的連接埠轉送；該連線的主機金鑰確認和登入問題會顯示在桌面窗格。

- RDP 會檢查伺服器憑證，並支援網路層級驗證（NLA）。VNC 支援傳統 VNC 密碼，或螢幕共享用的 Mac 帳號和密碼。
- RDP 桌面預設跟著窗格大小。連線設定的 **解析度** 可以固定遠端尺寸，畫面會縮放到窗格大小。**針對 Retina 顯示器最佳化** 只在配合視窗大小時可用。**連線品質** 可從最佳畫質（區域網路）調整到最快（慢速網路）。
- 打開 **共用剪貼簿** 後，任一邊拷貝的文字都能在另一邊貼上，RDP 和 VNC 皆可。
- 標題列有全螢幕按鈕。打開 **自動重新連線** 時，中斷的連線會自行重新連線。
- 印表機、智慧卡、聲音、麥克風、攝影機和共用資料夾不會重新導向。

## 9. 其他連線

在新連線分頁的 **其他連線** 區塊開啟或儲存：

| 類型 | 設定 |
|---|---|
| 序列埠 | 裝置（從已連接的裝置中選）、300 到 921600 的速率、資料位元、同位檢查、停止位元、流量控制（RTS/CTS、DTR/DSR 或 XON/XOFF），以及文字編碼。 |
| Telnet | 主機、連接埠和文字編碼。 |
| Mosh | 主機、帳號和 SSH 連接埠。使用登入 shell 中安裝的 `mosh`。 |
| Docker 容器 | 容器（可列出執行中的容器）、context、shell 和使用者。 |
| Kubernetes pod | Pod、context、namespace、容器和 shell。 |
| AWS Systems Manager | 執行個體、設定檔和區域。 |

序列埠表單開啟時會搜尋裝置，選取序列埠期間每秒更新一次。新表單的裝置欄空白，且只接上一個 USB 序列埠轉接器時，會自動帶入裝置與名稱。多個轉接器時請從選單選擇；既有連線的裝置和手動輸入的路徑會保留。選單也列出藍牙與系統連接埠，可按 **重新整理** 立即搜尋。命令列可用 `gloamux sessions serial-ports` 列出相同的可用路徑。

## 10. 自動化

### 常用指令

**常用指令** 側欄可以保存單行指令。

- **新增指令** 用名稱儲存一個指令，**搜尋指令** 可以篩選。
- **插入** 把指令輸入到選取的終端，但不按 Return，讓你可以修改。
- **執行** 先顯示指令和目的地，確認後輸入並按 Return。

### 輸出觸發

**設定 › 觸發** 會監看所有終端的輸出。按 **新增觸發規則**，設定 **名稱**、**比對文字**（純文字或正規表示式，可選 **區分大小寫**）和 **動作**：顯示通知、播放音效或標記分頁。每條規則在每個終端最多每 10 秒觸發一次。觸發規則絕不會輸入任何內容。

工作區資料夾內的 `triggers.json` 無法讀取或已損壞時，**設定 › 觸發** 會顯示這個問題，Gloamux 也不會改動這個檔案。修復或還原它之後，按 **重試**。

### Runbook

**終端 › Runbook** 保存含 `sh`、`bash`、`zsh` 或 `console` 程式碼區塊的 Markdown runbook。

1. 選擇一個連線。
2. 確認指令和目的地後，執行一個區塊或全部區塊。有環境標記的連線會顯示警告。
3. 有 Shell 整合時，Gloamux 會等每個區塊完成，在第一個失敗處停下，並保存每個區塊的結束狀態和輸出。

### 同時輸入到多個終端

- ⌥⌘I 同步輸入到分割中的所有窗格。
- **多重執行**（工作台）同步輸入到視窗中的每個終端，唯讀的除外。
- 經典版面的輸入列可以把一行文字送到 **所有工作階段**。

### 指令面板

⇧⌘P 可以找已存連線、已開啟的分頁，或任何工作區動作，例如分割、版面、主題、錄影和 runbook。輸入 `user@host` 可直接連線，貼上 `sftp` 指令可存成連線。

## 11. 安全

### 環境

從連線或資料夾的右鍵 **環境** 選單，標記為 Production、Staging、Test 或 Development。連線會沿用所在資料夾的標記。標記會為分頁上色、框住窗格，並顯示在工具列和工作階段視窗的標題。

### 高風險指令

在 **設定 › 安全 › 這些環境要確認高風險指令** 選擇的環境中（預設為 Production 和 Staging），符合規則的指令會等你確認才執行。預設規則涵蓋 `rm -rf`、`shutdown`、`mkfs`、`dd of=`、`DROP TABLE`、沒有 `WHERE` 的 `DELETE FROM`、`kubectl delete`、`terraform destroy`、`git push --force`、`systemctl stop` 和 `chmod -R` 等指令。在 **規則** 中每行寫一個正規表示式來修改，或按 **還原預設值**。

### 主機能否連線

**顯示主機能否連線** 每隔幾分鐘對每個可見的已存主機的 SSH 連接埠開啟並關閉一次 TCP 連線，不會嘗試登入，結果以連線樹中的圓點顯示。可在 **設定 › 安全** 關閉。

### 剪貼簿

只有打開 **允許程式寫入剪貼簿** 後，程式才能用 OSC 52 寫入你的剪貼簿。程式永遠無法讀取剪貼簿。

## 12. 匯入、匯出與備份

### 匯入連線

從工具列的 **新連線** 選單選 **匯入連線**，或從連線樹 **+** 選單選 **匯入**。Gloamux 會先顯示預覽。

| 來源 | 檔案 |
|---|---|
| Xshell | 工作階段檔、包含它們的資料夾，或支援的 `.xts` 備份 |
| OpenSSH | `~/.ssh/config` 或其他設定檔 |
| MobaXterm | `.mxtsessions` 或 `MobaXterm.ini` |
| PuTTY 和 KiTTY | 從登錄檔匯出的工作階段（`.reg`） |
| CSV | 含 `host` 欄位的檔案 |
| Gloamux | `.gloamuxsessions` 檔 |

Gloamux 會保留資料夾，並讀取帳號、連接埠、金鑰、代理和跳板。MobaXterm 的 SSH 閘道和 PuTTY 的 SSH 代理會變成跳板連線，PuTTY 的連接埠轉發也會保留。密碼絕不會被匯入。預覽會列出略過的項目和需要檢查的設定，例如原本在 Windows 上的金鑰檔。

### 匯出連線

**+** 選單的 **匯出所有連線**，或資料夾右鍵選單的 **匯出資料夾**，會寫出 Gloamux 連線檔、CSV 檔或 OpenSSH 設定。這些匯出檔含有連線資訊和金鑰路徑，分享前請先檢查。密碼和私鑰內容不會包含在內。個人資料夾內的金鑰路徑會寫成 `~/…`。

CSV 欄位：`host`（必填），以及選填的 `folder`（例如 `Team/Prod`）、`name`、`port`、`username`、`protocol`（`ssh` 或 `sftp`）、`identity file`、`proxy type`、`proxy host`、`proxy port` 和 `jump`（另一列的 `folder/name`，或 `user@host:port`）。

### 全部設定存成一個檔案

**設定 › 一般 › 全部設定 › 輸出** 會把連線和帳號、常用指令、觸發規則、runbook、主機金鑰、主題、版面、設定和密碼庫存成一個 `.gloamuxconfig` 檔，旁邊附一個 `.sha256` 檔。

- 密碼庫仍以主密碼加密，主密碼不會存進檔案。這台 Mac 記住的密碼不會包含在內。
- **匯入** 會用 `.sha256` 核對檔案、取代上述所有內容，並重新啟動 Gloamux。原本的內容會先保存在 Gloamux 資料夾的 `Backups` 資料夾。
- 沒有密碼庫的備份不會動到目前的密碼庫。

## 13. 外觀與文字

- 工具列的 **工作區主題** 或 **設定 › 外觀** 提供 73 種工作區主題：Gloamux 自己的主題、Ubuntu、Kali、GNOME、KDE Breeze、Tango 和 Linux 主控台等 Linux 配色，以及 GitHub、One Dark Pro、Dracula、Tokyo Night、Catppuccin、Nord、Gruvbox 等熱門的 Visual Studio Code 主題。可以用名稱搜尋。所有終端都使用選取的主題。

## 15. AI 代理（MCP）

AI 代理存取預設關閉。

1. 打開 **設定 › AI 代理**，打開 **允許 AI 代理**。
2. 把 **MCP 指令**（`gloamux mcp`）加到 AI 代理的 MCP 設定。Claude Code 的寫法是：`claude mcp add gloamux -- /Applications/Gloamux.app/Contents/Resources/bin/gloamux mcp`。
3. 在 **允許的連線** 按 **加入**，或在連線的右鍵選單選 **允許 AI 代理**。

AI 代理可以：

- 以名稱和目的地看到允許的連線，絕不會拿到密碼或金鑰。
- 在 Gloamux 中開啟允許的連線。
- 讀取你用 **終端 › 分享給 AI 代理** 分享的文字：選取範圍、上一個指令的輸出或整個畫面。認得出的密碼、權杖和私鑰會先換成 `[REDACTED]`。其他格式的機密仍可能漏掉，分享前請自己看過。
- 提議指令。Gloamux 會把分頁帶到前面，顯示代理、連線、目的地、原因和完整指令；只有你按 **執行**，而且只在同一個仍在連線的終端中才會執行。

**活動紀錄** 列出每個請求，包括被拒絕的。**撤銷所有存取** 會關閉 AI 代理存取、移除所有允許的連線，並停止等待審核的指令。

## 16. 更新

- **Gloamux › 檢查更新** 會到 GitHub 查詢新版本、顯示更新內容，用 Gloamux 內建的金鑰驗證簽章後安裝，再重新開啟 Gloamux。
- Gloamux 預設每天檢查一次新版本，不會先詢問。要停止，請在 **設定 › 一般** 關閉 **自動檢查更新**。已經關閉的人，更新後仍維持關閉。
- 更新檢查透過 HTTPS 向 GitHub 取得更新清單。請求的 User-Agent 包含 App 與 Sparkle 版本，GitHub 也會收到網路請求和來源 IP。Gloamux 維持關閉 Sparkle 系統資訊蒐集。見[資料保護](DATA-PROTECTION.md)。
- 更新功能從 Gloamux 1.1 開始提供。Gloamux 1.0 沒有更新功能，請用新版 DMG 手動替換一次。

## 20. 命令列一覽

`Gloamux.app` 內含 `gloamux` 指令，`gloam` 是它的簡短名稱。加入路徑：

```sh
export PATH="/Applications/Gloamux.app/Contents/Resources/bin:$PATH"
```

工作區指令接受 `--workspace PATH`，改用另一個 Gloamux 工作區。`--version` 和 `completion` 等工具指令不使用工作區。管理類指令輸出 JSON。結束代碼：0 成功、1 操作失敗、2 用法錯誤、130 被 Ctrl-C 中止。用 `gloamux 指令 --help` 查看詳細說明。

Gloamux 開著時，工作區指令會在 App 裡執行。等待 Touch ID 或主機探索的指令不會擋住其他指令。如果 Gloamux 在 20 秒內沒有接手，指令會撤回、不會執行，可以放心重試。如果 Gloamux 已接手但 5 分鐘後還沒回覆，或在執行途中結束，指令會說明狀況且不會自動重送；請先確認是否已生效。需要 Touch ID 的設定，若等待期間連線被改過就不會儲存，請重新執行指令。

| 指令 | 操作 |
|---|---|
| `gloamux ssh SESSION` | 在目前的終端開啟已存 SSH 連線的 shell，並以遠端 shell 的結束狀態結束。選項：`--password-stdin`、`--vault-password-stdin`、`--host-key FINGERPRINT`、`--interactive`。 |
| `gloamux files OP --session S` | `ls`、`pwd`、`stat`、`get`、`put`、`mkdir`、`mv`、`rm`、`rmdir`、`chmod`。選項：`--protocol sftp\|scp\|ftp\|ftps`、`--recursive`、`--overwrite`、`--resume`、`--allow-plain-ftp`、`--json`，以及 `ssh` 的登入選項。Ctrl-C 會刪除未完成的檔案。 |
| `gloamux sftp SESSION` | 登入一次，從終端或標準輸入讀取 `sftp` 指令（`ls`、`cd`、`get`、`put`、`mkdir`、`rename`、`rm`、`chmod` 等）。也接受帶主機的 `sftp` 選項，或用 `--command FILE\|-` 讀入整段貼上的指令。選項：`--password-stdin`（密碼或 session key）、`--vault-password-stdin`、`--host-key FINGERPRINT`、`--overwrite`。 |
| `gloamux history` | `list [COUNT [SEARCH]]`、`show`、`log ID PATH`、`export PATH.csv\|PATH.json`、`remove`、`clear`。 |
| `gloamux sessions` | `list`、`show`、`mkdir`、`add`、`edit`、`options`、`add-other`、`edit-other`、`serial-ports`、`rename`、`move`、`remove`、`env`、`auth`、`cert`、`from-sftp`、`import`、`export`。 |
| `gloamux hosts` | `list`、`history`、`clear-history`、`trust`、`replace`、`remove`、`export`（輸出成 `known_hosts`）、`discover bonjour\|tailscale\|aws`。 |
| `gloamux tabs` | `list`、`show`、`open`、`open-window`、`connect`、`local`、`select`、`rename`、`duplicate`、`close`、`disconnect`、`reconnect`、`split`、`unsplit`、`broadcast`、`multiexec`、`window`、`attach`、`read`、`send`、`run`、`readonly`、`log`、`record`、`encoding`、`integration`、`view`、`colors`、`highlights`。需要 App 正在執行。 |
| `gloamux forwards` | `list`、`add`、`remove`（已存規則）；`live-list`、`start`、`stop`（執行中的轉發）。類型：`local`、`remote`、`dynamic`。 |
| `gloamux commands` | `list`、`add`、`edit`、`remove`、`send`、`run`（常用指令）。 |
| `gloamux triggers` | `list`、`add`、`edit`、`enable`、`disable`、`remove`。動作：`notify`、`sound`、`mark`。 |
| `gloamux runbooks` | `list`、`show`、`create`、`import`、`delete`、`run`。 |
| `gloamux recordings` | `list`、`export`（輸出成 `.cast`）、`remove`。 |
| `gloamux appearance` | `list`、`get`、`set THEME_ID`。 |
| `gloamux settings` | `list`、`get`、`set`、`reset`。名稱見[設定一覽](#19-設定一覽)。 |
| `gloamux layout` | `get`、`set default\|classic\|workbench`。 |
| `gloamux config` | `export PATH`、`import PATH`（先結束 Gloamux）。 |
| `gloamux mcp` | 透過 MCP 把允許的連線提供給 AI 代理。 |
| `gloamux agents` | `status`、`history`、`clear-history`、`revoke`、`off`。 |
| `gloamux vault` | `status`、`lock`。 |
| `gloamux signins` | `list`、`remove`（需先通過 Touch ID 或 Mac 密碼；絕不印出密碼）。 |
| `gloamux workspace` | `lock`。 |
| `gloamux xserver` | `status`、`start`（XQuartz）。 |
| `gloamux completion` | `zsh`、`bash`。 |
| `gloamux benchmark` | 測量終端的吞吐量、重繪和回顯時間。 |
| `gloamux --version` | 印出 App 版本。 |
| `gloamux --self-test` | 檢查九項內附功能合約。 |

範例：

```sh
gloamux sessions add "Work server" ssh server.example.com deploy
gloamux sessions options "Work server" jump=Bastion x11=on
gloamux sessions options "Work server" jump=Bastion,Inner   # 先經 Bastion，再經 Inner
gloamux ssh "Work server"
gloamux files get --session "Work server" /var/log/app.log ./app.log
gloamux files put --session "Work server" ./build.tar.gz /srv/releases/ --overwrite
gloamux tabs list
gloamux tabs run TAB_ID "uptime"
gloamux forwards start TAB_ID local 8080 localhost 80
gloamux hosts discover bonjour
gloamux settings set terminal.font-size 14
```

要啟用 shell 自動補全，在 zsh 執行 `source <(gloamux completion zsh)`（先執行 `autoload -Uz compinit && compinit`），或在 bash 把 `gloamux completion bash` 存成檔案再 `source`。
