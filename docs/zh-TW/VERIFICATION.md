## Gloamux 1.4.2 (build 11)：連線歷史記錄指令、路徑與檔案變更（2026 年 11 月 25 日）

以 `7e91e50`（1.4.1 build 10）為基礎。連線歷史的一筆紀錄現在包含該次連線執行的指令、經過的跳板和 Proxy、連接埠轉送，以及檔案變更。指令由 `CommandCapture` 讀取送出 Return 時終端顯示的那一行。

- **單元測試。** `CommandCaptureTests` 涵蓋輸入、叫回、補全、貼上、預先輸入、折行和續行的指令、右側與會變動的提示字元、Shell 整合、tmux 類畫面，以及不回顯、以星號顯示或沒有換行的密碼。`ConnectionHistoryTests` 涵蓋路徑、搜尋、匯出，以及遮蔽參數裡的機密。
- **真實伺服器。** 打包的 CLI 以 `ssh-agent` 的金鑰，經由跳板登入 Ubuntu 24.04 OpenSSH 伺服器的虛擬終端。紀錄包含跳板和每個指令，包括歷史叫回、Tab 補全、Ctrl-R、分兩行的 `for` 迴圈，以及在另一個指令執行中輸入的指令。輸入給 `read -s` 的文字不在檔案裡，`mysql` 的 `-p` 已遮蔽。
- **本機 zsh。** 同一個讀取程式在登入 zsh 上，開或不開 Shell 整合都讀到每個指令。
- **App。** 用改名的打包版和隔離工作區連本機示範伺服器：指令和下載出現在連線歷史、篩選和跳板路徑有顯示，關閉 `history.commands` 後指令就不再記錄。
- `swift test`：**521 項，通過 513、略過 8、失敗 0**，在 `CommandCapture` 最後修正之前；其測試在修正後通過。`release.sh build` 會在發布 commit 重跑測試。
- 未檢查：Mosh、序列埠裝置、網路設備、fish、經 SSH 閘道的遠端桌面，以及真實的 Proxy。終端大小和伺服器得知的不同、讓 Shell 覆寫自己那一行時，可能漏記指令。

### 序列埠偵測與終端重設（2026 年 11 月 25 日）

以 `8bbc564`（1.3.1 build 7）為基礎的工作樹完成驗證。本機候選版位於 `build/serial-reset-fix/Gloamux.app`，版本資訊仍為 1.3.1 build 7，這次修正收錄於 1.3.2。工作樹保留原有的終端分享遮蔽修改與三項新增的 `AgentAccessTests`，本次測試也包含它們。

- **序列埠偵測。** 表單開啟時搜尋，選取序列埠期間每秒更新；離開表單或切換類型會取消 task，也可按重新整理立即搜尋。透過 IOKit 上層 USB 裝置辨識轉接器，不依賴驅動命名。只有新表單的空白裝置欄、且僅一個 USB 轉接器時自動帶入；多個轉接器、已儲存裝置和手動路徑保留使用者選擇。搜尋不開啟連接埠。三項 `SerialDeviceTests`、PTY 位元組收送與線路設定測試通過；封裝版 `sessions serial-ports --json` 列出相同可用路徑。

- **完整驗證。** `swift test`：**498 項，490 通過、8 跳過、0 失敗**。略過項目仍為三項外部 SSH 和五項 Xshell 樣本檢查。`package-app.sh` 成功；深度嚴格簽章驗證與 **9/9** 功能自我檢查通過；`git diff --check` 通過。未更動 Rust 原始碼，封裝時已建置 Rust helper，未另跑 Rust 測試套件。
