## 連線與工作區

- [x] 啟動時開本機終端分頁。已存連線放在可搜尋的資料夾樹，支援新增、編輯、重新命名、以複製貼上複製、移動和刪除。
- [x] 在分頁或獨立視窗開啟已存連線。預覽 Xshell 資料夾匯入，並保留匯入的資料夾階層。
- [x] 以左右或上下排列顯示兩個獨立終端。
- [x] 從頂列和 CLI 提供預設、經典和工作台版面，變更會立即套用，並保留到下次啟動。
- [x] 從指令面板連到 `user@host`；從指令面板、選單列、Spotlight、捷徑和 `gloamux://` 連結開啟已存連線和分頁。
- [x] 從經典版面的網址列以 `ssh://user@host:port`、`user@host` 或主機名稱連線。
- [x] 以分頁重新打開上次啟動的已存連線和本機終端（設定 › 一般）。某個啟動連線失敗時，其他分頁仍會開著。
- [x] 把分頁拖到窗格上分割、分割數量不限，並可把窗格從分割中取出成為自己的分頁。
- [x] 依編號選擇分頁、用快速鍵切換、重新排序和重新命名。
- [x] 在原分頁旁複製分頁、把分頁移到自己的視窗，再把該視窗移回分頁列而不中斷連線。
- [x] 從經典和工作台版面的工具列，以及從視窗本身進入全螢幕。
- [x] 從經典版面的工具列開始記錄檔、匯入醒目提示組、打開觸發和鎖定工作區。
- [x] 從工作台版面的功能區同時輸入到視窗中所有終端（MultiExec）、啟動 XQuartz、打開已存密碼，以及列出每個已連線 SSH 工作階段的通道和連線數。CLI 以 `gloamux tabs multiexec`、`gloamux xserver`、`gloamux signins` 和 `gloamux forwards live-list` 做同樣的事。
- [x] 預覽後匯入 Xshell 資料夾、MobaXterm 匯出、OpenSSH 設定、CSV、PuTTY 和 KiTTY 登錄檔匯出，以及 Gloamux 連線檔。匯出 Gloamux 連線檔、CSV 和 OpenSSH 設定。
- [x] 為團隊匯出不含密碼的設定檔。每個 macOS 帳號的儲存空間各自獨立。

## SSH、信任與網路

- [x] 支援 SSH 密碼和 OpenSSH Ed25519 金鑰檔登入、主機金鑰檢視與固定，以及可選的加密密碼庫。
- [x] 支援最多八層 SSH 跳板；SOCKS4、SOCKS4a、SOCKS5 和 HTTP CONNECT 代理；本機、反向和動態轉發；以及手動重連。
- [x] 加入鍵盤互動式驗證和多重要素提示，包含多回合，以及公鑰加驗證碼。
- [x] 以 OpenSSH agent 金鑰，以及 Ed25519、ECDSA 和 RSA 金鑰檔登入。
- [x] 在連線編輯器中依連線選擇是否轉發 SSH agent。產生 OpenSSH 格式的 Ed25519 金鑰檔，可選擇以密語加密。
- [x] 選擇連線的 SSH 演算法：「新式」，或加上 `diffie-hellman-group16-sha512` 與 `diffie-hellman-group14-sha256` 給舊伺服器用的「相容」。像 `ssh` 的 `SendEnv` 一樣，把這台 Mac 的 `LANG` 與 `LC_*` 提供給 shell。
- [x] 閒置時送出可設定的 keepalive、Mac 喚醒後檢查連線，並可選擇自動重連中斷的已存連線（2、5、10、30 秒後，之後每 60 秒）。
- [x] 把本機、反向和動態通道存進設定檔，連線後自動啟動。連線中以及從選單列都能啟動、停止和儲存規則。本機監聽使用回送介面。

## 終端、外觀與記錄

- [x] 在終端中繪製 UTF-8、Unicode 框線、ANSI 屬性、256 色和 RGB 色。提供整個工作區的配色預設和語言設定。
- [x] 在終端游標位置顯示穩定的方塊。支援獨立的滑鼠文字選取，並遵循終端的游標顯示設定。
- [x] 選擇終端字型和大小，用 ⌘+、⌘− 縮放並用 ⌘0 重設，選擇可閃爍的方塊、底線或直線游標（程式可用 DECSCUSR 變更），並降低背景透明度以透出模糊的桌面。
- [x] 選擇連線的編碼（UTF-8、Big5、GB18030、Shift JIS、EUC-JP、EUC-KR、ISO Latin 1）、設定回捲長度、在游標處以輸入法組字，並把滑鼠點按、拖曳、移動、滾輪（X10 和 SGR）及焦點回報給程式。按住 Option 拖曳仍可選取文字。
- [x] 寬度改變時重新換行主畫面和回捲，游標和 Shell 整合標記會跟著文字。
- [ ] 加入可重複的 tmux、Vim 和全螢幕主控台程式相容性檢查。
- [x] 雙擊選取單字、三擊選取整行。用 ⌘F 搜尋終端和回捲，可用一般文字或正規表示式、可區分大小寫，標示所有符合項目，並用 ⌘G 和 ⇧⌘G 逐一跳轉。
- [x] 多行貼上送出前可預覽和編輯；使用者開啟後，程式可用 OSC 52 寫入剪貼簿。剪貼簿讀取要求一律不回應。
- [x] 選取即拷貝、中鍵貼上、雙擊用的單字字元，以及貼上時去掉前後空白或合成一行。拷貝時會接回終端自動換行的行。**終端 › 從歷史貼上** 列出最近拷貝和貼上的文字，含有可辨識密碼的文字不會保留。
- [x] **終端 › 拷貝模式** 用鍵盤選取和拷貝（`h j k l`、`w`、`b`、`0`、`$`、`g`、`G`、`v`、`V`、`y`），**終端 › 顯示時間戳記** 顯示每行最後變動的時間。
- [x] 接收 `sz` 傳來的檔案，並把檔案傳給 `rz`（ZMODEM），有進度列和取消按鈕；取消下載不會留下不完整的檔案，畫面上也不會出現殘留資料。
- [x] 字型連字、行距與字距、彩色文字的最小對比度，以及給中日韓伺服器用的雙寬「寬度不明確字元」。
- [x] 在任何 App 中用全域快速鍵（⌃\`、⌥\`、⌥Space 或 F12）顯示或隱藏下拉工作區視窗。
- [x] 匯入 Xshell 醒目提示組，並在終端中為符合的關鍵字上色。
- [x] 長時間指令在非作用中分頁完成時標記分頁並送出 macOS 通知（需 Shell 整合）。
- [x] 響鈴可設為閃爍、系統音效或關閉，並標記響鈴的非作用中分頁。在窗格標頭顯示程式設定的標題。
- [x] Gloamux 在背景時，響鈴會讓 Dock 圖示跳動。
- [x] 關閉會中止工作的分頁前先確認、把終端設為唯讀，以及手動或閒置後鎖定工作區，並以 Touch ID 或 Mac 密碼解鎖。
- [x] 標記你沒在看的分頁有新輸出，以及任何分頁的連線中斷。
- [x] 以純文字或含跳脫序列的方式儲存記錄檔，可針對所有連線或單一終端，並遮蔽可能的機密。
- [x] 每次連線與傳輸的檔案存成一筆紀錄，可檢視、搜尋、匯出或下載。
- [x] 把終端顯示的內容存成文字檔，或用預設文字編輯器打開。

- [x] 同時輸入到分割群組中的每個窗格，並可切換停止。
- [x] 從經典版面的輸入列把一行送到目前的連線或所有開啟的連線。
- [x] 在每個新 shell 中輸入已存連線的啟動指令。
- [x] 新增以一般文字或正規表示式比對的輸出觸發，可發出通知、播放聲音或標記分頁。設定 › 觸發可列出、編輯和停用規則，每條規則在每個終端中每 10 秒最多觸發一次。
- [ ] 發布與 GUI 操作對等的正式 CLI。使用相同的應用程式操作和工作區、穩定的連線 ID、終端模式、機器可讀輸出、取消、結束代碼和 Shell 補全。撰寫安裝說明，並為每項 GUI 功能測試兩個入口。

- [x] 提供給核可連線用的本機 MCP 伺服器。提供簡短的分享終端片段、提議的指令、可見的活動、依連線設定的權限、指令執行前的審閱，以及撤銷。代理的檔案傳輸操作尚未實作。憑證資料留在 Gloamux 的控制下。

## 檔案傳輸與遠端編輯

- [x] 在 GUI 中從 SSH/SFTP 連線瀏覽資料夾，以及上傳、下載、重新命名和刪除檔案。下載失敗時保留本機檔案。
- [x] 在工作台版面中，把遠端檔案清單顯示在終端旁邊。
- [x] 在遠端清單旁顯示本機檔案清單、跟隨 shell 目前的資料夾、欄位排序，並可直接在檔案瀏覽器開啟已存的 SSH 設定檔。
- [x] 從貼上的 `sftp` 指令存成連線、傳輸指令裡的檔案，之後每次只問新的 session key；CLI 有 `gloamux sftp`。
- [x] 在檔案傳輸的兩側顯示或隱藏隱藏檔。
- [x] 建立資料夾、顯示權限和修改時間、從 Finder 拖入檔案，以及遞迴上傳和下載資料夾並顯示進度。
- [x] 在檔案傳輸中一次選取多個檔案，並連同內容刪除遠端資料夾。
- [x] 像 Finder 一樣瀏覽檔案側欄：用箭頭展開、雙擊打開、選取多個檔案下載，以及一次上傳多個檔案。每筆傳輸各有一列，顯示百分比、剩餘時間和剩餘大小。
- [x] 變更遠端檔案權限，並把遠端檔案和資料夾拖到 Finder。
- [x] 排入傳輸佇列、取消單筆或全部，並選擇取代或略過已存在的檔案。
- [x] 連線中斷後重試傳輸、SFTP 和 FTP 從中斷處繼續，中斷後保持本機和遠端檔案完整。SCP 會從頭開始。
- [x] 被動式 FTP 以及明確和隱含 FTPS 設定檔，具備憑證驗證、受保護的 FTPS 資料連線和 GUI 檔案操作。
- [x] FTPS 資料連線會沿用控制連線的 TLS 工作階段，所以要求重用工作階段的伺服器（例如設定 `require_ssl_reuse` 的 vsftpd）也能連線。
- [x] 使用 SSH 信任和驗證的舊式 SCP 上傳和下載。可儲存的選項有 SFTP、SCP 和 SCP 後備。回送測試環境會停用 SFTP 來測試後備。
- [x] 以快速查看預覽本機和遠端檔案。
- [x] 用本機編輯器編輯遠端檔案：下載、編輯，再經衝突檢查上傳，並保留檔案權限。

## 超出 Xshell 與 MobaXterm 基準的項目

這些項目來自 2026 年 11 月 20 日的腦力激盪，涵蓋參考產品沒有定義的 macOS 原生、現代終端、機群和品質工作。

### macOS 整合

- [x] 在 Secure Enclave 產生無法匯出的 SSH 金鑰，並顯示公鑰供複製到伺服器。
- [x] 在同一次 App 啟動期間以 Touch ID 解鎖密碼庫，並可選擇每次連線都以 Touch ID 確認。
- [x] 加入選單列項目，用於快速連線、最近的連線，以及啟動、停止和檢查已存通道。
- [x] 透過 App Intents 把已存連線和常用操作提供給捷徑，並在 Spotlight 為已存主機建立索引。使用與 CLI 相同的共用操作。
- [x] 以快速查看預覽遠端檔案。

### 現代終端功能

- [x] 以 OSC 133 提示字元標記加入 Shell 整合：在提示字元間跳轉、選取指令輸出、顯示結束狀態，並在非作用中分頁的長時間指令完成時通知。
- [x] 透過 OSC 7 追蹤遠端工作目錄，用於檔案窗格跟隨資料夾，以及在同一位置開新分頁。
- [x] 支援 OSC 8 超連結和偵測到的網址。顯示以 sixel、iTerm2 協定或 kitty 圖片協定傳來、有大小限制的內嵌圖片（見開發指南）。不支援 kitty 動畫與 Unicode 佔位字元。
- [x] 以可重複的基準測試量測終端吞吐量和輸入延遲。評估 Metal 繪製與目前繪製器的差異。
- [x] 提升解析器吞吐量：成批寫入連續的可列印 ASCII、解碼 UTF-8 時不為每個字元建立 `String`，並逐位元組解析 CSI 參數（純文字從 22 提升到約 100 MB/s，彩色記錄從 17 提升到 36 MB/s）。以查表取得字元寬度，並把其他文字一次寫入一整列（中日韓文字從約 19 提升到約 70 MB/s）。
- [x] 加入 ⌘⇧P 指令面板，透過共用應用程式操作列出每個操作。

### 機群與環境工作流程

- [x] 從 Bonjour `_ssh._tcp` 服務、Tailscale 節點，以及 AWS EC2 或 SSM 清單探索主機。加入連線樹前先預覽探索到的主機。
