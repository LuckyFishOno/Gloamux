# Gloamux 路線圖

[English](../en/ROADMAP.md) · [繁體中文](ROADMAP.md) · [回到 README](../../README.zh-TW.md)

2026 年 11 月 24 日工作目錄的功能與壓力測試結果見[驗證紀錄](VERIFICATION.md)。

[功能待辦](FEATURE-BACKLOG.md)追蹤 Xshell 8 和 MobaXterm 26.6 有文件記載的工作流程，以及它們在 macOS 上的對應做法。Tabby 和 Termius 則是工作區導覽和外觀的參考。

目前版本為 **Gloamux 1.3.1 (build 7)**。App 與 CLI 一起發布，1.1 起提供 Sparkle 更新。CLI 尚缺遠端桌面輸入。

## 第一階段里程碑

1. 建立共用的應用程式操作和產品 CLI，能列出已存連線並依設定檔連線。
2. 為 CLI 檔案指令補上其餘的檔案工作區操作。
3. 為 CLI 補上其餘 GUI 操作和即時工作區控制。
4. 把同一套共用操作延伸到本機 MCP 伺服器和接下來的連線種類。

## 命令列與 MCP

- [ ] **CLI 對等。** 每個 GUI 操作都必須有對應的 `gloamux` 指令，涵蓋連線和資料夾管理、匯入、驗證與主機金鑰檢視、終端和分頁控制、檔案傳輸、轉發、已存指令、外觀和工作區偏好設定。每種新連線也適用同樣的要求。會顯示視窗的指令可以請執行中的 App 打開或排列視窗。目前已涵蓋：代理存取狀態、紀錄和撤銷（授權仍在 App 內進行）、連線、資料夾、其他連線（序列埠、Telnet、Mosh、容器、Pod 和 SSM）與序列裝置清單、每個 SSH 連線選項（`sessions options`）、遠端桌面通道與顯示選項、主機金鑰移除、匯出與清除紀錄、主機探索、錄影、分頁錄影、Shell 整合、終端或檔案傳輸畫面、環境標籤、匯入與匯出、匯出和匯入所有設定、主機金鑰及其紀錄、`gloamux ssh`、快速連線、跨視窗的分頁和終端、分割、每個分頁的顏色和醒目提示、檔案傳輸、轉發、快速指令、輸出觸發、操作手冊、設定、版面、配色和鎖定。仍只在 GUI：遠端桌面的輸入。建立、解鎖或變更密碼庫，以及顯示已存密碼，刻意只留在 App 內。
- [x] 在 GUI 和 CLI 之間共用應用程式操作、工作區資料和即時工作階段識別碼。先從列出連線和依已存設定檔連線開始。在適用處為自動化提供穩定的結束代碼和結構化輸出。每項功能都要從兩個入口驗證過才算完成。
- [x] **本機 MCP 伺服器。** 透過 [MCP stdio](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports) 公開選定的應用程式操作。讓代理能列出核可的連線、打開或找到核可的連線、讀取使用者分享的終端輸出片段，並準備指令讓使用者在 Gloamux 中審閱。已以 `gloamux mcp` 完成，它會把每次工具呼叫轉給執行中的 App。
- [x] 提供需主動開啟的 MCP 存取、依連線設定的權限、可見的活動紀錄，以及立即撤銷。執行前顯示完整指令和目的地，並要求在 Gloamux 中確認。憑證留在 Gloamux 內，核可綁定到特定的即時工作階段。

## 檔案傳輸

- [x] **SFTP GUI。** 透過既有的 SSH 連線瀏覽、上傳、下載、重新命名和刪除檔案。已存設定檔可以直接開到檔案瀏覽器。
- [x] **SFTP 版面。** 在工作台的側欄中，把遠端檔案顯示在終端旁邊，並可選擇跟著 shell 所在的資料夾。
- [x] **遠端檔案樹與檔案傳輸視窗。** 預設版面的右側欄以資料夾樹顯示目前窗格的檔案：伺服器的登入資料夾，或本機終端的這台 Mac 家目錄。雙欄畫面（這台 Mac 和一台伺服器，類似 WinSCP 或 FileZilla）在預設版面佔用主視窗，在經典和工作台版面則開在自己的視窗。它提供 Finder 拖放、遞迴資料夾傳輸、可取消的佇列、取代或略過的衝突處理，以及管線化的 SFTP 讀寫。
- [x] **SFTP 工作區與 CLI。** 已完成：跟隨資料夾、隱藏檔、多重選取、從檔案側欄上傳和下載多個檔案、每筆傳輸的進度、快速查看、連同內容刪除資料夾、權限、拖到 Finder、續傳，以及有明確上傳和衝突處理的遠端編輯。`gloamux files` 提供同樣的檔案操作：列出、詳細資訊、檔案和整個資料夾的上傳與下載（可續傳）、資料夾、重新命名、連同內容刪除檔案和資料夾，以及權限。
- [x] **FTP 與 FTPS GUI。** 以已存設定檔連線，並使用檔案瀏覽器和佇列。被動式 FTP、明確和隱含 FTPS、憑證驗證和受保護的資料連線都有回送測試。
- [x] **SCP GUI。** 使用舊式 SCP 和已存的 SSH 驗證上傳與下載。可選 SCP、SFTP 或 SCP 後備。後備和兩個傳輸方向都在停用 SFTP 的 OpenSSH 上測試過。
- [x] **跨協定的檔案 CLI。** 用已存設定檔透過 SFTP、SCP、FTP 和 FTPS 列出、查看、上傳、下載、續傳支援的傳輸、重新命名、建立和刪除資料夾、刪除檔案及設定權限。
- [x] **工作區 CLI 基礎。** 管理已存連線和資料夾、匯入設定檔、檢視 SSH 主機金鑰、控制分頁、管理 SSH 轉發和快速指令，以及選擇配色。提供 JSON 輸出、結束代碼，以及 Zsh 和 Bash 補全。
- [x] **跨協定的傳輸。** 進度、取消、覆寫處理、佇列、失敗時保留既有檔案、連線中斷後重試，以及 SFTP 和 FTP 的續傳，都是共用的，並在可拋棄的測試環境上測過。

## SSH 與終端

- [x] 三種工作區版面（預設、經典和工作台），工具列選單立即套用、記住選擇，並可用 CLI 讀取和設定。經典的工具列和工作台的功能區可以使用記錄檔、醒目提示組、觸發、工作區鎖定、MultiExec、XQuartz、已存密碼和通道清單。
- [x] 預覽並匯入 OpenSSH 設定，支援 include、萬用字元預設值、agent 設定和跳板路由。支援 Ed25519、ECDSA 和 RSA 金鑰檔與 agent 金鑰、最多八層跳板，以及 SOCKS4/4a/5 和 HTTP CONNECT 代理。
- [x] 在 App 內啟動和停止本機、反向和動態轉發。把規則存在連線設定檔，連線後自動啟動。
- [x] 在同一次 App 啟動期間以 Touch ID 重新打開密碼庫。建立、顯示和重新產生由 App 管理的 Secure Enclave SSH 金鑰，不需每次連線都用 Touch ID。
- [x] 密碼或金鑰密語第一次登入成功後存在這台 Mac，重新開機後不需解鎖就能連線。也可選擇每次連線都要求 Touch ID 或 Mac 密碼。
- [x] 鍵盤互動式驗證和多重要素登入，包含多回合提示，以及公鑰加驗證碼，透過在內附的 NIOSSH 中加入 RFC 4256 支援來完成。
- [ ] 在有 PAM 和一次性驗證碼的真實 OpenSSH 伺服器上驗證鍵盤互動式登入。
- [x] 每個連線的 SSH agent 轉發，以及產生 Ed25519 金鑰檔。
- [x] 連線恢復：可設定的 keepalive、Mac 喚醒後檢查，以及已存連線可選的自動重連。
- [x] 多窗格工作區：任何窗格都能左右或上下分割，數量不限，可拖曳分隔線、最大化和還原窗格，並同時輸入到所有窗格。
- [x] 重新打開上次啟動的分頁、依編號選擇分頁、重新排序和命名分頁、關閉前確認、鎖定工作區，以及每個連線的啟動指令。
- [x] 複製分頁，以及把分頁移到自己的視窗再移回分頁列。
- [x] 可搜尋、插入且執行前會確認的已存快速指令。
- [x] Shell 整合：OSC 133 提示字元標記（在提示字元間跳轉、選取輸出、結束狀態、隱藏分頁中長時間指令完成的通知）、用於新分頁和檔案樹的 OSC 7 資料夾，以及 OSC 8 與偵測到的連結。另有 ⌘⇧P 指令面板、會遮蔽機密並可匯出 asciinema 的錄影、Markdown 操作手冊、會確認高風險指令的環境標籤，以及 `docker`、`kubectl` 和 SSM 工作階段。
- [x] 支援正規表示式的終端搜尋、記錄檔、響鈴、字型與縮放、游標形狀、背景透明度、回捲長度、每個連線的編碼、輸入法組字、滑鼠與焦點回報、多行貼上預覽，以及需主動開啟的 OSC 52 剪貼簿寫入。
- [x] 輸出觸發：某一行符合時發出通知、播放聲音或標記分頁。
- [x] 分頁上的輸出和中斷指示，以及長時間指令完成和響鈴的標示。
- [x] 終端寬度改變時重新換行。
- [ ] 擴大 Vim、tmux 和中文輸入法的相容性測試。
- [x] 連線匯入和匯出，包含 MobaXterm 和 CSV。支援與團隊分享設定檔而不含憑證。匯入也能讀 PuTTY 和 KiTTY 的登錄檔匯出及 Gloamux 連線檔；匯出會寫成不含密碼的 Gloamux 連線檔、CSV 和 OpenSSH 設定。

## 其他連線

- [x] **內嵌 RDP 和 VNC。** 兩種協定都能存在連線樹。在 Gloamux 分頁中登入、檢視桌面，並使用鍵盤和指標。本機測試環境涵蓋 RDP 憑證核可和 NLA，並驗證兩種協定的畫面解碼和輸入。
- [x] RDP 變更解析度、全螢幕和重新連線。VNC 剪貼簿。透過 SSH 通道的 RDP 和 VNC。
- [x] RDP 剪貼簿文字。
- [x] 在真實 Windows 伺服器上驗證桌面工作流程。
- [ ] 在真實 VNC 伺服器（例如 macOS 螢幕共享）上驗證桌面工作流程。
- [x] 打開內建或 USB 序列裝置，可設定鮑率、資料位元、同位元、停止位元和流量控制。
- [x] 把 X11 從受信任的 SSH shell 轉發到 XQuartz。回送測試檢查授權替換、被拒絕的連線和 shell 結束時的清理。
- [x] 以已安裝的用戶端開啟 Mosh 工作階段，以及內建終端類型和視窗大小協商的 Telnet 工作階段。
- [ ] 以 XQuartz 驗證 X11 的繪製和輸入。
